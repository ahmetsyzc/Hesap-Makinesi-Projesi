# 🧮 Hesap Makinesi Projesi

Hesap Makinesi Projesi, C# Windows Forms kullanılarak geliştirilmiş basit bir masaüstü hesap makinesi uygulamasıdır.

Proje; Windows Forms bileşenlerini kullanmak, kullanıcı girişlerini yönetmek ve klavye olayları üzerinde pratik yapmak amacıyla geliştirilmiştir.

## 🚀 Özellikler

- Toplama işlemi
- Çıkarma işlemi
- Çarpma işlemi
- Bölme işlemi
- Ondalıklı sayılarla işlem yapabilme
- Girilen son karakteri silme
- Ekranı tamamen temizleme
- Klavye üzerinden sayı girişi
- Klavye üzerinden matematiksel işlem girişi
- Enter tuşu ile sonucu hesaplama
- Backspace ile son karakteri silme
- Delete veya Escape ile ekranı temizleme
- Hatalı işlemlerde kullanıcıya uyarı gösterme

## ⌨️ Klavye Desteği

Uygulama fare kullanımının yanı sıra klavye üzerinden de kontrol edilebilir.

- `0-9` → Sayı girişi
- `+` → Toplama
- `-` → Çıkarma
- `*` → Çarpma
- `/` → Bölme
- `Enter` → Sonucu hesaplama
- `Backspace` → Son karakteri silme
- `Delete / Escape` → Ekranı temizleme

## 🛠️ Kullanılan Teknolojiler

- C#
- .NET
- Windows Forms
- System.Data
- DataTable.Compute

## ⚙️ Hesaplama Yapısı

Kullanıcının girdiği matematiksel ifade uygulama içerisinde oluşturulur ve `DataTable.Compute()` kullanılarak hesaplanır.

Ondalıklı sayılarda Türkçe sayı formatıyla uyumluluk sağlamak amacıyla virgül ve nokta dönüşümü yapılmaktadır.

amacıyla geliştirilmiştir.
